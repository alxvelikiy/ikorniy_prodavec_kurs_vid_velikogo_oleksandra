# D1. Карта маскота «Ікринка» (текстовая, на согласование)

Статус: **черновик до сверки с ref1–ref4** (файлов в окружении пока нет). Стиль персонажа (3D «глина/винил» по R1)
здесь не утверждается — карта описывает *где, когда и как* появляется маскот; *как он выглядит* решит D2/арена.
Текущий маскот: SVG, 8 эмоций (idle, happy, excited, sad, thinking, cheer, coach, sleepy), 4 действия
(blink, wave, jump, nod), 4,7 KB gzip (см. `D0_AUDIT.md` §3).

## 1. Экран × поза × эмоция × анимация × частота

| Место | Поза / аксессуар | Эмоция | Анимация (reduce-motion → только смена позы) | Частота |
|---|---|---|---|---|
| Онбординг | машет рукой | happy | вход снизу пружиной, wave, затем «дыхание» | 1 раз |
| Путь, у текущей части | стоит рядом, смотрит на узел | happy → sleepy после 60 с простоя | дыхание; tap по маскоту — jump | постоянно, 1 экземпляр |
| Обложка дня (шапка блока) | поза по теме дня (гачок — удочка, заперечення — щит…) | разная | без движения, параллакс ≤ 8 px при скролле | 5 обложек |
| Плеер: теория | с блокнотом | thinking | лёгкий nod при появлении | на каждой карточке теории |
| Плеер: верно | мини-поза в листе (48 px) | happy / excited | pop + squash&stretch 200 мс | **не каждый шаг**: 1-й верный в части, затем комбо 3/5/10 |
| Плеер: ошибка | мини-поза в листе | sad («ой») | короткий shake 150 мс | 1-я ошибка в части и при сердцах ≤ 2; иначе без маскота |

| Босс: интро | гарнітура, встаёт рядом с осетром | coach (решительный) | вход сбоку | каждый босс |
| Босс: пройден / «Ще раз» | корона / подбадривает | cheer / coach | jump / nod | каждый раз |

| Профіль | «витрина» достижений, корона если есть | happy / proud | без движения | постоянно |

## 2. Правила частоты (чтобы не раздражал)

1. В плеере маскот реагирует **на события, не на шаги**: 1-й верный, комбо 3/5/10, 1-я ошибка, сердца ≤ 2, конец части.
2. Не чаще одного появления на 4 шага и не чаще раза в 20 с (кроме итогов и листов).
3. Никогда не перекрывает вопрос, варианты ответа и кнопку «Перевірити».
4. Один маскот на экране (исключение — босс: маскот + осётр).
5. `prefers-reduced-motion`: без движения, только смена позы/эмоции; конфетти нет (как сейчас).
6. Звук и вибрация — только через `Duo.signals` (на устройстве, решение `project-context.md`).
7. Простой: дыхание после 6 с, sleepy после 60 с; любое касание — проснулся.

## 3. Аксессуары по событиям

| Аксессуар | Событие |
|---|---|
| навушники | звук / налаштування сигналів, «Я на дзвінку» |
| солнцезахисні окуляри | серія ≥ 3 дні, комбо |
| корона | скриня, досягнення, бос пройдений |
| гарнітура | бос, ШІ-тренер |
| блокнот | теорія, шпаргалка |
| прапорець фінішу | частина / урок пройдено |
| секундомір | розминка перед дзвінком |
| лупа | робота над помилками |
| святковий ковпак | ціль дня виконано |

Итого поз/эмоций для 3D-рендера (если R1): ~16 (8 эмоций × базовая поза + 8 поз с аксессуарами).

## 4. Хранение и вес (оценка до D2; реальные числа — после рендера образца)

| Вариант | Вес | Плюсы | Минусы |
|---|---|---|---|
| SVG (как сейчас) | 4,7 KB gzip все эмоции; +0,3–0,6 KB на аксессуар | ничтожный вес, анимация частей (моргание, рот) | плоский, не R1 |
| Растровые 3D-спрайты WebP/AVIF с альфой | поза 256×256 CSS-px (512 px @2x): WebP ~25–45 KB, AVIF ~15–30 KB; 16 поз ≈ 0,4–0,7 MB всего | вид R1 (свет, матовость) | вес; анимация только трансформами целиком (нет моргания) |
| Lottie | плеер ~40–60 KB gzip JS + анимации | плавная анимация частей | **не влезает** в бюджет JS плеера (70 + 40 > 80) |
| Гибрид (рекомендация) | растровые позы, лениво по экрану (≤ 2–3 на экран ≈ 60–120 KB); тень — CSS radial-gradient (0 KB); движение — CSS-трансформы (пружина, squash, дыхание) | вид R1 + «живость» без JS-веса | нужен пайплайн рендера (D2) и кэш (sw.js) |

Ленивая загрузка: `loading="lazy"` + `<link rel="preload">` только для позы текущего экрана; на слабом
телефоне — AVIF, если поддерживается, иначе WebP; при `Save-Data` — SVG-запасной вариант.
Бюджет картинок предложу после замера образца b2 (D2).
