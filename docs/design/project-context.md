# Контекст проекта: DUO-редизайн (ветка design-duo)

Сюда записываются осознанные продуктовые решения, которые не видны из кода.

## 2026-09-30. Звук и вибрация только на устройстве

Звук и вибрация хранятся только на устройстве (`localStorage`: `ikorka-duo-sound`, `ikorka-duo-haptics`, логика в `sfx.js`), не синхронизируются с аккаунтом и не дублируются в `Duo.progress.settings`. Решение осознанное. Пересмотреть, если пользователи будут жаловаться на сброс настроек при смене устройства.
