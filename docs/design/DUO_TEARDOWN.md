# DUO_TEARDOWN — паттерны Duolingo → наш аналог (курс продаж Ikorka Shop)

Сводный разбор (2026-09-28) двух исследований: [research/lesson.md](research/lesson.md) — всё ВНУТРИ урока,
[research/meta.md](research/meta.md) — всё ВНЕ урока. Источники — только публичные материалы (блог Duolingo,
UX-кейсы, галереи микроанимаций, справочные вики); ни логинов, ни скачанных ассетов. Копируем паттерны,
механики и тайминги, но не персонажей, иллюстрации, звуки, шрифты и тексты Duolingo.

**Итого паттернов: 100** (внутри урока — 52, вне урока — 48).
Приоритеты: P0 — 57, P1 — 28, P2 — 15.
Уверенность: high — 34, med — 35, low — 7, смешанная — 38.
Оговорка: в исследовании урока живой веб-поиск в сессии был недоступен (сбой классификатора окружения) — факты
реконструированы по известным публичным материалам, отсюда больше `low` (в основном числа: тайминги, easing, пороги).

Правило приёмки (раздел 12 задания, пункт 5 «Duo-паритет»): для экрана закрыты ВСЕ паттерны P0/P1 из чек-листа ниже.

## 3. Тайминги-сводка (из исследования урока)

| Событие | Длительность / easing | Наша рекомендация |
|---|---|---|
| Рост прогресс-бара (верно) | ~400–600 мс, spring/overshoot (low) | `springGrow`: cubic-bezier(0.34,1.56,0.64,1) или реальная spring (stiffness ≈300, damping ≈20) |
| Sheet вверх (feedback/exit) | ~250–350 мс ease-out на вход, ~150–200 мс на выход (low) | единые `Duo.motion.dur.base`/`.fast` для `sheetUp`/`sheetDown`, без отдельных чисел на каждый случай |
| Shake неверной карточки | ~300–400 мс, 3–4 угасающих колебания (med) | keyframes с уменьшающейся амплитудой, а не единичный cubic-bezier |
| Heart break | ~300–400 мс, лёгкий tremor перед сменой иконки (low) | синхронизировать конец с началом sheet «неверно» |
| FLIP плитки word bank | ~200–300 мс ease-out (med) | использовать уже спроектированный `Duo.motion.flip` без изменений |
| CountUp XP / точность | ~600–900 мс, ease-out с замедлением к финалу (med) | `countUp(el, from, to, {ms: 700})` + `xpTick` на каждый шаг |
| Stagger карточек статистики | шаг ~150–250 мс между карточками (low) | `Duo.motion.stagger(els, fn, 200)` |
| Confetti на завершении урока | ≤ 1.4–1.5 с (high — уже зафиксировано контрактом) | `confetti({ms: 1400})` без изменений |
| popIn (выбор варианта / бейдж комбо) | ~120–200 мс ease-out, overshoot до ~1.05 scale (low) | одна функция `popIn` на оба случая, не дублировать |
| Переход между шагами урока | ~150–200 мс fade/slide (low) | синхронизировать с началом `springGrow`, чтобы читалось одним движением |
| Idle-моргание маскота | цикл 3–6 с, только в viewport (med — совпадает с уже описанным в meta.md для пути) | тот же `Duo.mascot.mount({idle:true})`, не отдельная реализация для урока |
| Двойная вибрация «неверно» | 2 коротких импульса подряд (low) | `navigator.vibrate([40, 60, 40])` вместо одного числа |

## 4. Порядок празднований после урока (из исследования мета-слоя)

Последовательность экранов, которые могут появиться после завершения урока — **никогда одновременно**, каждый
ждёт тап «Продовжити», прежде чем показать следующий (это уже заложено как контракт `Duo.celebrate.enqueue/run()`
в `docs/design/ARCHITECTURE.md`, и совпадает с общей UX-практикой не стекировать модалки):

1. **`lessonComplete`** (всегда) — экран статистики урока: XP, точность, ошибки. Если 0 ошибок — усиленная
   «perfect»-версия (см. строку 42 таблицы) вместо обычной.
2. **`streak`** — показывается, только если это первый засчитанный урок за день (`firstToday`). Полноэкранное
   пламя + инкремент числа. Если число «круглое» (7/30/100/365 и т.п.) — специальная юбилейная версия вместо
   обычной (строка 21), но это **тот же слот очереди**, не отдельный попап.
3. **`goal`** — показывается, только если дневная цель достигнута именно этим уроком (`reachedNow`). Кольцо
   прогресса заполняется до конца.
4. **`quest`** — если этим уроком закрыто одно или несколько ежедневных заданий: рекомендация — **один экран
   со списком** выполненных заданий, а не отдельный попап на каждое (иначе очередь может растянуться на 3+ экрана
   подряд, что утомляет; это наша рекомендация, не подтверждённый факт из Duolingo).
5. **`achievement`** — если этим уроком разблокировано достижение. Если их несколько — по одному, в конце очереди.
6. *(вне этой очереди, P2)* **`league`/результат лиги** — не привязан к конкретному уроку, показывается один раз
   при входе в приложение в момент недельного сброса (понедельник-эквивалент), отдельно от пост-урочной серии.

Условие показа каждого шага — соответствующий флаг/данные из `completeNode()` (`firstToday`, `goal.reachedNow`,
`quests: [...]`, `achievements: [...]`). Если ни одно условие не выполнено — очередь состоит только из
`lessonComplete`, пользователь мгновенно возвращается на путь.
