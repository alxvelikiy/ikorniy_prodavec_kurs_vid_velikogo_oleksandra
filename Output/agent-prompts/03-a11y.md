# 03-a11y: доступность плеера урока

**Цель.** Довести `vprava.html` (плеер урока) до WCAG 2.1 AA: фокус, aria, контраст, клавиатура, reduced motion, скринридер.

**Входные файлы (читай точечно).** `v2/build/assets/duo/lesson.js`, `exercises.js`, `lesson.css`, `signals.js` (если есть), `v2/build/duo/pages/vprava.mjs`; инструменты проверки: axe-core в `v2/mvp/tests/package.json` (если нет, `npm install` в `v2/mvp/tests`), dev-shot: `v2/duo/tools/dev-shot.mjs`.

**Что проверить и исправить.**
1. axe-core на каждом из 8 типов шагов, на листах результата, листе выхода, «серця закінчились», экране итога: 0 нарушений уровня serious/critical, в обеих темах.
2. Фокус: после «Перевірити» фокус на листе результата, после «Далі» на заголовке следующего шага; фокус-ловушка в модальных листах, Esc закрывает, фокус возвращается на вызвавший элемент; `:focus-visible` виден в обеих темах (≥ 3:1).
3. Порядок Tab = визуальный порядок; плитки build/order и пары match управляются с клавиатуры без мыши; цифры 1–9 не срабатывают, когда фокус в поле ввода.
4. aria: `aria-live` для результата и комбо, `role=radiogroup/radio` у вариантов, `aria-pressed` у плиток, `aria-label` у крестика и сердец (на украинском), `aria-valuenow` у прогресса.
5. Контраст всех текстов ≥ 4.5:1 (крупные ≥ 3:1), disabled-кнопка ≥ 3:1, состояния correct/wrong различимы не только цветом (иконка или текст).
6. reduced motion: нет движения, звук и логика сохранены; вибрация выключена.
7. Масштаб текста 200% и ширина 320 px: без горизонтальной прокрутки и обрезанного текста.

**Критерий готовности.** Скрипт `Output/a11y-run.mjs` (или путь в отчёте) запускает axe на всех состояниях и печатает 0 нарушений; ручные пункты 2–4 проверены тестом с клавиатуры.

**Ограничения.** Правки точечные (Edit), файлы целиком не читай; не меняй логику упражнений и данные уроков; git не используй; скриншоты только на контрольной точке. Отчёт ≤ 15 строк: изменения по пунктам, результат axe, что не проверено (скринридер на живом устройстве).
