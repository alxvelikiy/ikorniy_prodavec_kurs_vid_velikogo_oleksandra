# Дизайн-система курсу Ikorka Shop

Затверджено 2026-09-23. Ціль: робочий інструмент для новачка відділу продажів — не консюмерський бренд, не маркетинг-лендинг. План обговорення і повне обґрунтування — у сесії; тут лише зафіксовані рішення для розробки.

## Анти-slop чек-лист (свідомо уникаємо)

- Кремовий фон + serif + теракота — НІ. Фон нейтрально-холодний сірий, акцент не теракотовий.
- Майже чорне тло + кислотний акцент — НІ. За замовчуванням сайт світлий; темна тема — лише за перемикачем, на токенах (див. «Темна тема»), без кислотних акцентів.
- Broadsheet (hairline/нульовий radius/газетні колонки) — НІ, це не редакційний сайт.
- Однакові SaaS-картки з однаковою тінню на будь-який факт — НІ, є явна ієрархія (Tier 1 / Tier 2).
- CAPS-eyebrow над кожним заголовком, мета-рядки через мідл-крапку — НІ, caps лишається тільки на бейджі «День N з 5».
- Псевдо-преміальний майже-чорний (#0B0B0B/#111) — НІ, `--ink:#23262B` (холодний slate, не намагається виглядати «преміально»).
- Моно-шрифт для дрібних цифр — НІ, Manrope + `font-variant-numeric: tabular-nums`.
- «→» в кінці кожного лінка/кнопки — не додаємо.

| Токен | Hex | Роль |
|---|---|---|
| `--ink` | `#23262B` | основний текст |
| `--canvas` | `#F3F4F6` | фон сторінки |
| `--paper` | `#FFFFFF` | картки/панелі |
| `--brand` | `#A8432B` | єдиний «гарячий» акцент (асоціація з ікрою): прогрес, головна цифра уроку, CTA |

| `--good` | `#2E8B57` | тільки фідбек тесту — вірна відповідь |
| `--bad` | `#B23A3A` | тільки фідбек тесту — невірна відповідь |

**Джерело істини для стилю (рішення 2026-09-23):** мокап уроку 9 (https://claude.ai/artifact/NYQEKmRVKqrUoT9NGLiN9B, `project/Main.dc.html`) — пілот редизайну всього курсу. У питаннях стилю мокап головніший за сайт, крім явних порушень уже прийнятих бізнес-правил (напр. іконки при підрозділах — тут правий цей документ). Текст і цифри мокапу — не джерело: вони розходяться з `text/lessons/urok_09.md`.

**Де лежать значення:** `build/lib/tokens.mjs` → під час збірки генерує `assets/tokens.css` (світла і темна тема). У CSS/JS кольори вписувати не можна — тільки токени (зокрема кільце/донат: `--ring-fill`, `--ring-track`).

### Темна тема (затверджено 2026-09-23)

Окремі темні значення з мокапу, не CSS-інверсія: `--canvas #1E1B19`, `--paper #28241F`, `--ink #F2EDE7`, `--line #3A352F`, `--text-dim #948C82`, `--info #3FA9A4`, `--good #4CAF77`, `--bad #E17169`. Темний `--brand` обчислюється зі світлого тим самим способом, що в мокапі: `mix(#A8432B, 0.32)` = `#C47F6F`. Текст на заливці `--brand`/`--good` у темній темі — `--on-brand #1E1B19` (білий дає 3,18:1 — нижче AA). Обкладинки — колір по дню (`--tint-1…5`), темні відтінки тієї ж світлості, що coverTint мокапу. `--line` і `--text-dim` у світлій темі — як на сайті, не з мокапу. Перемикач «Темна тема / Світла тема» — у шапці, вибір зберігається в браузері (`ikorka-theme`). PNG-лого не перемальовується: у темній темі лежить на світлій плашці `--logo-plate`.

Старі змінні `--neon-*` (зараз означають протилежне назві — `--neon-pink` це насправді оранжево-червоний) прибираються разом із рефактором карток.

## Типографіка

**Один шрифт — Manrope** (рішення 2026-09-23). Unbounded прибрано: округла геометрія літер читалась як дитячий/консюмерський додаток. DOU (перевірено в DevTools 2026-09-23) тримає всі заголовки в нейтральному гротеску Commissioner 700; Manrope 800 дає той самий характер без нової залежності.

- **H1** — Manrope 800, `letter-spacing:-.02em`.
- **Усе інше** — Manrope: H2/H3 (bold/extrabold), body, лейбли, кнопки.
- Шкала: H1 32–44px (clamp), H2 22–24px, H3 17–18px, body 16px, дрібний текст 13px.
- CAPS — тільки бейдж «День N з 5».

## Іконки

Одне правило: іконка тільки для трьох типів заперечень (Істинні/Ситуативні/Хибні) — фіксована мапа 3→3, без нечіткого пошуку по ключових словах (`pickIconKey`/`ICON_KEYWORDS` видаляються). Усюди інше — типографічні картки без іконок.

**Значки при заголовках розділів — ТАК (рішення замовника 2026-09-23, пізніше, скасовує попередню заборону).** Маленький значок Lucide (ISC) у плашці `--brand-soft` перед кожним H2 уроку; мапа «розділ → значок» — `SECTION_ICONS` у `build/lib/undraw.mjs`. Картки лишаються без іконок.

## Ієрархія фактів

**Правило Tier-1 (затверджено 2026-09-23):**
1. Один Tier-1 на урок, задається явно: усі інші `:::stat` уроку мають `подача: цитата` (pull-quote у тексті). Чипів Tier-2 більше немає — уроки 1/2/3/6 переведено 2026-09-23.
2. Кандидат — власні дані відділу (записи дзвінків / навчання), що прямо вимірюють навичку уроку, бажано зі знаменником. Зовнішні дослідження — ні. Немає органічного кандидата — Tier-1 немає (урок 9).
3. Форма → візуал: «N з M» → донат (у центрі «N», під ним «з M», ніколи «N/M»); «A проти B» з двома числами → два бари; «шкала» — лише якщо в числі є реальні точки діапазону; усе інше → велике число без графіка.
4. Верхня межа («до N з M», урок 11) — не частка, а велике число без графіка.
5. «26 з 26» — повне кільце допустиме.

Вигляд Tier-1 (патерн мокапу): донат 96 px поруч із числом і підписом, пунктирна рамка `--line`. Pull-quote: лінія зліва `--info`, число кольором тексту.

## Ілюстрації

Одноколірна лінійна ілюстрація на місці `:::scene`, сухий самоіронічний тон (DOU-стиль), оригінальна, без мем-шаблонів і впізнаваних персонажів. Одна сцена на урок, там де є природний привід.

**Готові ілюстрації, не ручне малювання (рішення замовника 2026-09-23).** Ручне SVG-малювання фігур не дає рівня DOU. Джерело — unDraw (перший вибір), за потреби DrawKit / Storyset; для кожного смислового розділу — найближча за дією/настроєм ілюстрація. Перефарбування одним акцентом: `#6c63ff` → `--brand` (той самий колір, що донат), нейтральні → `--illo-dark/mid/light` (окремі значення для темної теми), тон шкіри без змін. SVG вбудовуються в сторінку й окремими файлами не роздаються (ліцензія unDraw). Код: `build/lib/undraw.mjs`, файли — `build/illos/`.

Структура DOU: головна ілюстрація «Що це» — у картці з підписом; інші розділи — ілюстрація праворуч від тексту (на телефоні — над текстом). Разом 5 ілюстрацій + значки розділів на урок.

**Стан виконання (2026-09-24):** урок 1 затверджено замовником 2026-09-23; патерн увімкнено на всіх 12 уроках (`REDESIGN_PAGES` у `build/build.mjs`). Скріншоти всіх уроків (світла + темна, 1280 px) — `v2/shots/urok-NN-{light,dark}*.png`, знімаються `node v2/build/shot.mjs urok-NN`.

**«Типові помилки»** — директива `:::pairs` («картка: помилка | як правильно»); «як правильно» — лише з тексту того ж уроку; порожнє — показується тільки помилка.

## Тест

Реальний вибір з варіантів замість `<details>`-toggle: клік по варіанту → одразу `--good`/`--bad` підсвітка + коротке пояснення.

## Мобільний

Уточнення: раніша знахідка про відсутній `<meta name="viewport">` виявилась хибною тривогою — перевірка йшла на `v2/course` (навмисно "голі" HTML-фрагменти без doctype/head/meta, призначені для вставки в Artifact-хостинг). Реальний деплой-сайт `v2/site` (Netlify) вже містить viewport-тег у `shellPage()` (`build.mjs`), і `@media (max-width:640px)` там працюють штатно. Прев'ю-сервер (`preview-server.mjs`) перемкнутий на `v2/site`, щоб надалі тестувати правильний білд.
