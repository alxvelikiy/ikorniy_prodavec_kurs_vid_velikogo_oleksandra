# День 5. Фінал дзвінка і самоатестація

## Мета дня

Довести дзвінки до повного фіналу — склад, сума, відділення, оплата, строк, подяка — і пройти самоатестацію: порівняти свої дзвінки з записами найкращих дзвінків відділу за всіма 12 навичками, зробивши не менше 75 дзвінків.

## Повторення (10 хвилин)

- Назви по пам'яті три шкали, за якими оцінюєш дзвінок після завершення.
  Звір себе: впевненість клієнта в продукті, у менеджері, у компанії — кожна від 1 до 10.
- Чому заборонено слово «чому» у відповідь на відмову клієнта?
  Звір себе: воно вимагає від клієнта вголос обґрунтувати й тим самим закріпити відмову.

## Саморозбір увечері

Спочатку фінал дзвінка. Прослухай три дзвінки із замовленням і перевір: чи звучать склад, сума, відділення, оплата, строк і подяка до кінця, без обриву. Затвердженої формули прощання в матеріалах немає — орієнтир: фінали найкращих менеджерів відділу з уроку 12.

Далі — самоатестація за таблицею нижче. Порядок той самий, що й щодня: прослухав → порівняв (з прикладом з уроку і з записами найкращих дзвінків відділу) → вирішив, що виправити → проговорив виправлену репліку вголос і записав на диктофон.

Підсумок дня — 3-2-1, але сьогодні з горизонтом на перший тиждень у відділі: три речі, які вже виходять; дві — виправити; одну спробувати в перших дзвінках відділу.

## Самоатестація

Для кожної навички постав позначку «так», «частково» або «ні» і запиши номер дзвінка, на якому це видно. Еталон для порівняння — записи найкращих дзвінків відділу, а не власна пам'ять чи відчуття: майже всі вони успішні, тож порівнюй себе з прийомами з цих записів, а не з тим, що кожен дзвінок обов'язково закінчується замовленням.

| Навичка | Що має звучати | Так / Частково / Ні |
|---|---|---|
| Вступ | Ім'я клієнта раніше за назву компанії, одна пауза після привітання | |
| Гачок | Конкретний привід дзвінка одразу після вступу, без розмитих слів | |
| Впевненість, темп, інтонація, пауза | Одна манера до кінця дзвінка, без зайвих пауз, без «можливо» і «не впевнений» | |
| Чистота мови | Без «чому» і «можемо», без самопоправок у цифрах при закритті | |
| Етапи дзвінка | Усі етапи за порядком, блок властивостей не пропущено | |
| Персоналізація | Історія клієнта з картки прозвучала в перших фразах, ім'я клієнта — кілька разів | |
| УТП | Три шари презентації: характеристика → властивості → вигода | |
| Альтернатива і спуск | Спуск лише після повторного «дорого», подарунок збережено | |
| Підсумок і прощання | Склад, сума, відділення, оплата, строк перед прощанням | |
| Заклик до дії | Заклик утвердженням, повторний заклик після кожної обробки заперечення | |
| Робота із запереченнями | Раннє заперечення визнано коротко без паузи, на фінансове — два-три аргументи поспіль | |
| Знання продукту і мети дзвінка | Відповіді про склад і термін без паузи, клієнта класифіковано за готовністю | |

**Правило готовності.** Навичку вважай опрацьованою, коли позначка «так» повторюється щонайменше на трьох різних дзвінках, а не на одному вдалому. Курс вважаєш пройденим, коли всі 12 навичок мають позначку «так». Там, де лишилося «частково» або «ні», — повернись до відповідного уроку й дня і повтори фокусні дзвінки, перш ніж вважати навичку закритою.

Заповнений лист самоатестації — це твій особистий підсумок курсу. Хто і за якими додатковими критеріями ухвалює рішення про перехід у відділ, у матеріалах курсу не описано — тут зафіксована лише твоя власна оцінка за 12 навичками.

## Челендж дня

У кожному замовленні дня звучить повний підсумок: склад, сума, строк доставки. Мета — всі замовлення без винятку.

## Типова яма цього дня

Повного фіналу дзвінка після замовлення в записах рядових менеджерів практично немає: більшість дзвінків обривається без завершальної фрази. Ймовірна яма дня — дзвінок закінчується на оплаті, без підсумку.

Окремо про строк підготовки. У записах навчання термін розходиться: у середньому п'ять-шість днів, у важких випадках — до двох тижнів. П'ять днів — нижня межа цього розкиду. Якщо за підсумками самоатестації навичка позначена «ні» або «частково», поверніться до її уроку й дня і повтори фокусні дзвінки, перш ніж вважати підготовку завершеною.
