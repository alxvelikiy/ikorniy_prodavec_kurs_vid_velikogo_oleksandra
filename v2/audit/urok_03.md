## Что изменилось относительно a3/lesson_K05.md

- Метки, коды, таймкоды сняты по SPEC v2 п.2; формулировка «крючок или 2–3 квалифицирующих вопроса» из старого a3-урока убрана и заменена на «одне-два уточнювальні питання... необов'язковий крок» — прямое соответствие обновлённому решению заказчика (SPEC v2 п.7).
- Добавлена иллюстрация из нового документа — схемы допродажу по сету 998→1549 (image_2025-10-16_19-43-34.png) — как конкретный наглядный пример уже существующего в курсе принципа «допродаж сразу после согласия». Конкретные суммы (333/150/450 грн) сознательно не перенесены в текст для менеджера, чтобы не дублировать материал уроков 7–8, которые пишет другой агент; в аудите зафиксировано на случай пересечения.
- Добавлена связка с `x/pryama_liniya.docx.txt` для формулы «властивість → вигода» — раньше эта формула была помечена только «тільки в документах» (DOC-KURS) без примеров; теперь есть второй документ компании с конкретными живыми примерами. В текст для менеджера перенесена только краткая отсылка, полный разбор — в уроке 7.
- Арифметическая нестыковка «7+11+6=24, не 26» из a5/qa_report.md сохранена как открытый вопрос: в тексте для менеджера использована осторожная формулировка «близько 11», не заявлено полное покрытие.
- Практика полностью самостоятельная, без «розбір з наставником» — a3-урок уже был близок к такому формату, серьёзных правок не потребовалось.
