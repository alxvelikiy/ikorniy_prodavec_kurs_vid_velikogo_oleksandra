## 6. Аудит-файлы (только для заказчика, на русском) — `v2/audit/`

Для каждого текстового файла менеджера — парный аудит: `v2/audit/urok_NN.md`, `v2/audit/den_NN.md`, `v2/audit/chzv.md`.

```
# Аудит: Урок N. <Термин> (K<ID>)

| # | Утверждение в тексте для менеджера (коротко) | Метка | Источники и частота | stat в тексте | Примечание |
|---|---|---|---|---|---|
```

Метки — ровно три (+ подтип):
- `[Моя методика]` — паттерн встречается в транскриптах (ТОП / ОБ / ДЛ).
- `[Моя методика · документ компании]` — есть в документах компании, в звонках не подтверждён.
- `[Дополнено]` — внешняя техника, в материалах нет; указать, какой пробел закрывает, и URL/книгу.
- `[Со слов наставника]` — утверждение о «топах»/результатах без опоры на запись.

Старая метка `[Моя методика · только в документах]` → `[Моя методика · документ компании]`. Старая `[Моя методика · единичный случай]` → `[Моя методика]` с частотой «1».

## 7. Стоп-лист для самопроверки (перед сохранением файла менеджера прогнать поиском)

Регулярки, которых **не должно быть** в `v2/text/**`:
`K\d\d`, `К-?\d\d`, `ТОП-`, `ОБ-`, `ДЛ-`, `DOC-`, `@\d+:\d\d`, `РИС`, `Рис\.`, `Моя методика`, `Дополнено`, `Доповнено`, `Со слов`, `Зі слів наставника]`, `ВЕТКА`, `[Гг]ілка [A-IА-І]\b`, `\b\d+/\d+\b`, `🟢`, `🟡`, `⛔`, `📚`, `🎧`, `🚫`, `🏋`, `✅`, `95.140`, `\b100 дзвінк`, `обов'язков.. 2`, `обов’язков.. 2`.

Русские слова в тексте менеджера — ошибка (кроме цитат из звонков).
