# Паттерны LMS-сторінки уроку — що подивились і що взяли

Оглянуто: Skillbox, Яндекс Практикум, GeekBrains (маркетинг + загальновідома структура уроку),
Codecademy (learn.codecademy.com), Brilliant.org, Laba (laba.ua), Projector (prjctr.com — головна,
скріншот знято через вбудований браузер). Практикум/Skillbox/Codecademy/Brilliant тримають самі уроки
за логіном, тому їх layout звірявся по публічних лендінгах + документованій структурі courses (щоденний
досвід користування цими продуктами).

## Що працює у них і що взяли собі

1. **Вузька колонка тексту (~640–720px).** Жоден текстовий урок не розтягується на всю ширину —
   і в Практикумі, і в Codecademy текст урока обмежений, щоб рядок був 60–80 символів.
   → В `style.css`/`theme.css` явно зафіксували `--content-w:700px` для `.lesson-body, ul, ol, .quiz-q`.

2. **Закріплений індикатор прогресу уроку.** У Skillbox і Практикумі під час скролу уроку зверху
   видно тонку смужку прогресу проходження сторінки.
   → Додали `.read-progress` — тонка неонова смужка під топнавом, росте по скролу (JS у `fx.js`).

3. **Бокове міні-оглавління з підсвіткою активного розділу ("scrollspy").** У Практикумі й Codecademy
   праворуч/зверху є список розділів уроку, активний пункт підсвічується під час скролу.
   → Додали `.lesson-toc` — плаваюче праворуч (desktop ≥1180px) оглавління за `h2`/`h3` уроку,
   активний пункт підсвічується через `IntersectionObserver` (`fx.js`). На вузьких екранах — ховається,
   не заважає (немає окремого HTML від збірника, тому на мобільному просто не рендериться).

4. **Кольорові callout-блоки за змістом (важливо / приклад / попередження).** У всіх платформ є
   візуально відмінні "плашки" з іконкою/кольором під тип контенту, а не суцільний текст.
   → В курсі вже були `.hook`, `.challenge-text`, `.quote-card`, `.stat-panel` — довели їх до єдиної
   системи неонових рамок з кольором за змістом (`--neon-pink` — питання/гачок, `--neon-yellow` —
   виклик дня, `--neon-cyan` — цитата, `--neon-violet` — статистика).

5. **Чітка ієрархія H2/H3 з великим повітрям зверху.** У Codecademy/Практикумі заголовки розділів
   явно крупніші й контрастніші за текст, з великим відступом зверху, що ріже урок на «глотки».
   → Посилили `margin-top`/розмір `.lesson h2/h3`, додали неоновий градієнт на H1/H2 (тільки їх,
   як і вимагав бриф).

6. **Великі картки-виноски для ключових цифр/фактів (stat cards).** У Практикумі й Skillbox факти й
   цифри виносяться в окремі картки, а не ховаються в абзаці.
   → `.stat-card` лишили, перевели на скляні неонові поверхні на нових токенах.

7. **Кнопка "Наступний урок" — великий, контрастний елемент внизу сторінки, важко пропустити.**
   У Codecademy/Практикумі це явна кнопка-заклик, не просто посилання.
   → `.pagenav a.next` отримала неоновий заливний фон-градієнт (pink→orange→yellow), більший розмір
   тексту, hover-світіння — головна дія на сторінці.

8. **Чек-листи/завершення кроку з видимим станом "зроблено".** У Practicum/Codecademy виконані кроки
   явно закреслюються/змінюють колір — не просто чекбокс.
   → `.check-item.checked` і `.done-btn.on` зроблені контрастнішими на неоні (заливка кольором +
   світіння), щоб стан "зроблено" читався з першого погляду.

## Свідомо не взяли

- Багатоколонкові дашборди курсу (Практикум) — не підходить для короткого 5-денного self-study курсу
  без бекенда/акаунтів.
- Інтерактивні вправи в тілі уроку (Codecademy/Brilliant) — поза скоупом цього репаку (тільки дизайн).
- Окремий сайдбар-навігація на всю висоту сторінки (Skillbox) — конфліктує з тим, що кожен урок це
  окремий статичний HTML без спільного JS-стану меню; замінили компактним плаваючим міні-TOC.
