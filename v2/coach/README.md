# ІІ-тренер Ikorka Shop — локальний запуск

Сервер `v2/coach/server.mjs` роздає сайт курсу (`v2/site`) і робить два виклики до Claude API: репліку ІІ-клієнта (`/api/coach/roleplay`) і розбір відповіді (`/api/coach/feedback`). Потрібен лише Node.js 18+ (перевірено на 22), `npm install` не потрібен.

**Тільки локально** (рішення власника): сервер слухає `127.0.0.1` і не призначений для публічного деплою — ключ API лежить у змінній оточення цього комп'ютера.

## 1. Запуск

З кореня репозиторію (або з розпакованого `ikorka-mvp.zip`):

```bash
node v2/coach/server.mjs
```

Відкрити http://127.0.0.1:8787. Без ключа все працює, а тренер показує «Тренер офлайн».

## 2. Як задати ANTHROPIC_API_KEY

Ключ береться **лише зі змінної оточення**: у файли, логи й браузер він не потрапляє. Не зберігайте ключ у файлах репозиторію — автотест `static-checks.mjs` шукає його в кожному файлі.

| Система | Команда (у тому самому вікні, потім `node v2/coach/server.mjs`) |
|---|---|
| macOS / Linux (bash, zsh) | `export ANTHROPIC_API_KEY="sk-ant-…"` |
| Windows PowerShell | `$env:ANTHROPIC_API_KEY="sk-ant-…"` |
| Windows cmd | `set ANTHROPIC_API_KEY=sk-ant-…` |

Або одним рядком (bash): `ANTHROPIC_API_KEY="sk-ant-…" node v2/coach/server.mjs`.

У першому рядку лога сервер пише режим: `live, модель …`, `mock` або `офлайн — немає ANTHROPIC_API_KEY`. Сам ключ ніде не друкується.

Інші змінні:

| Змінна | Типово | Навіщо |
|---|---|---|
| `COACH_MODEL` | `claude-sonnet-5` | модель |
| `COACH_DAILY_LIMIT` | `40` | викликів моделі на добу |
| `PORT` / `HOST` | `8787` / `127.0.0.1` | адреса сервера (HOST не міняти без потреби) |
| `COACH_MOCK=1` | — | демо без ІІ: заготовлені відповіді, для перевірки інтерфейсу |
| `NODE_USE_ENV_PROXY=1` | — | якщо інтернет лише через проксі (`HTTPS_PROXY`): вбудований `fetch` у Node без цього проксі не використовує (перевірено на Node 22.22; Node пише попередження «experimental» — це нормально) |

## 3. Ліміт викликів

- Одна репліка ІІ-клієнта = 1 виклик, один розбір = 1 виклик. Повна розмова (8 реплік + розбір) — до 9 викликів, тобто 40 на добу вистачає приблизно на 4 повні розмови або 40 окремих розборів.
- Кожен виклик: max_tokens 400, тайм-аут 20 с.
- Доба рахується за UTC: лічильник обнуляється о 00:00 UTC (03:00 за київським літнім часом, 02:00 — зимовим).
- Лічильники лежать у `v2/coach/data/usage.json` (у `.gitignore`). Там **лише числа**: виклики, успіхи, помилки, тайм-аути, спрацювання ліміту, замінені фрази. Тексти розмов ніде не зберігаються.

**Що робити, коли ліміт вичерпано.** Сторінка показує «Тренер офлайн (вичерпано ліміт розборів на сьогодні)» і розбирає відповідь за правилами уроків. Курс працює повністю. Варіанти:
1. Дочекатися нової доби (UTC).
2. Підняти ліміт на сьогодні: перезапустити сервер з `COACH_DAILY_LIMIT=60`.
3. Скинути лічильник: зупинити сервер, видалити або відредагувати `v2/coach/data/usage.json`, запустити знову.

## 4. Як перевірити офлайн-режим

1. **Без ключа:** запустіть `node v2/coach/server.mjs` без `ANTHROPIC_API_KEY` і відкрийте `trener.html`. Статус має бути «Тренер офлайн», підказка — про розбір за парами уроків. Розбір будь-якої відповіді має прийти в три рядки, а «Що сказати натомість» — дослівно з уроку.
2. **Без сервера:** відкрийте `v2/site` через будь-який статичний сервер, напр. `python3 -m http.server -d v2/site 8080`. Сторінка одразу в офлайні й не робить жодного запиту до `/api`.
3. **Через API:**
   ```bash
   curl -s -X POST -H 'content-type: application/json' -d '{"ping":true}' http://127.0.0.1:8787/api/coach/feedback
   ```
   Відповіді бувають такі: `{"ok":false,"mode":"offline",…}` — ключа немає, `{"ok":true,"mode":"live",…}` — ключ є, `"mode":"mock"` — демо. Поле `left` показує, скільки викликів лишилось на сьогодні.
4. **Автотестом:** `cd v2/mvp/tests && npm install && node coach-api.mjs`. Серед іншого він перевіряє офлайн без ключа, ліміт і 10 спроб ін'єкції на запобіжниках сервера.

## 5. Жива перевірка (коли є ключ)

```bash
ANTHROPIC_API_KEY="sk-ant-…" node v2/mvp/tests/coach-live.mjs
```

Скрипт проводить 3 повні розмови з ІІ-клієнтом і розбір, потім 10 спроб ін'єкції. Результати записує у `v2/mvp/COACH_LIVE_TEST.md` і завершується з помилкою, якщо хоч одна спроба пройшла. Витрата — 32 виклики; ліміт скрипт задає собі сам і не чіпає лічильник сервера.

## 6. Захисти (коротко)

- **Заземлення.** Моделі передаються лише правила і фрагменти уроку сцени, до 3 КБ.
- **Валідатор.** Кожна рекомендована фраза перевіряється на дослівність за текстами уроків і не може бути з переліку помилок. Якщо перевірка не пройшла, фраза замінюється на «У курсі немає готової фрази — див. правило N».
- **Ввід менеджера.** Він вважається недовіреним: подається в тегах з інструкцією ігнорувати команди, довгі цифри маскуються.
- **Вартові.** Вони відкидають репліки ІІ-клієнта з цифрами чи умовами, витоком промпту, виходом з ролі, сторонніми темами або не українською. Репліка-ін'єкція чи репліка з вигаданими цифрами не може отримати оцінку «добре».
- **Персони.** `personas.json` і `scenes.json` — порожні заготовки під знеособлені сцени з реальних дзвінків; дані має передати pipeline.
