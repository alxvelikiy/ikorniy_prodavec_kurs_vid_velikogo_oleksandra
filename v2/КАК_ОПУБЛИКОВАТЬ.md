# Как выложить курс отдельным сайтом (без Claude)

Готовая к публикации версия курса лежит в папке `v2\site`. Это обычный статический сайт: HTML, CSS и JS, без сервера и базы данных. Его можно разместить на любом бесплатном хостинге.

## Вариант 1. Netlify Drop — самый простой, 5 минут

1. Откройте https://app.netlify.com/drop
2. Зарегистрируйтесь или войдите (подойдёт аккаунт Google). **Без входа сайт удаляется через час.**
3. Перетащите в окно браузера **папку** `v2\site` целиком, не отдельные файлы.
4. Через несколько секунд появится ссылка вида `https://случайное-имя.netlify.app`. Её и отправляйте людям.
5. Понятное имя ссылки: Site configuration → Change site name, например `ikorka-kurs` → `https://ikorka-kurs.netlify.app`.

**Как обновить курс после правок.**
1. Внесите правки в тексты `v2\text\` или попросите Claude.
2. Пересоберите курс командой `node v2/build/build.mjs` из папки проекта.
3. В Netlify откройте сайт → Deploys → перетащите папку `v2\site` ещё раз. Ссылка не изменится.

## Вариант 2. Cloudflare Pages — если нужен свой домен

1. https://dash.cloudflare.com → Workers & Pages → Create → Pages → **Upload assets**.
2. Укажите имя проекта и загрузите папку `v2\site`.
3. Ссылка будет `https://имя.pages.dev`. Свой домен (например `kurs.ikorka.shop`) подключается в Custom domains.

## Что важно знать

- **Доступ.** Ссылка открыта для всех, у кого она есть; поисковики сайт тоже могут найти. Если курс нужен только сотрудникам, на Netlify включите пароль (Site configuration → Access control → Password protection, это платная функция) или используйте Cloudflare Pages + Cloudflare Access (бесплатно до 50 пользователей).
- **Прогресс, отметки и карточки повторения** хранятся в браузере каждого сотрудника. На другом телефоне или компьютере они начнутся с нуля.
- **Внутренние файлы в сайт не попадают:** аудит источников (`v2\audit`) и рабочие материалы остаются только у вас.
- **Голосовое чтение** зависит от браузера: лучше всего работает в Chrome и Edge.
- **Видео на YouTube** на обычном хостинге открываются прямо на странице.
